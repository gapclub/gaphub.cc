# 关于 GapHub

GapHub 是一个中文社区。在这里，你可以分享经历、交流问题，也可以安静地记录当下。

官网：[gaphub.cc](https://gaphub.cc)

## 社区愿景

GapHub 的 slogan 是：

> Progress at your own pace.

我们相信，每个人都有自己的节奏。

有些时候适合向前，有些时候适合停下来歇一歇。

GapHub 希望成为一个让经历、问题和情绪都能被认真看见的地方。
